# Hotel Booking

## Вариант 3

**Предметная область:** система бронирования гостиничных номеров.

Приложение предназначено для демонстрации основных принципов разработки, управления версиями исходного кода и контейнеризации программного обеспечения.

## Функциональность

Система предназначена для работы с информацией о гостиничных номерах и их бронировании.

Пользователь может получать информацию о доступных гостиничных номерах.

Проект используется для демонстрации процессов разработки программного обеспечения, управления версиями исходного кода и контейнеризации приложения.
